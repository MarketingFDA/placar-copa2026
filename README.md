# Placar Copa 2026 — Fradema Championship

Placar interativo de desempenho por departamento, com visual inspirado na identidade da FIFA World Cup 2026.

## Como usar

- Clique em **+** para adicionar ponto ao departamento
- Clique em **−** para remover ponto
- O ranking se atualiza automaticamente
- Confetti aparece a cada ponto marcado

## Como rodar localmente

Abra o arquivo `index.html` direto no navegador. Não precisa de servidor.

## Deploy no GitHub Pages

1. Faça upload desta pasta em um repositório do GitHub
2. Vá em **Settings > Pages**
3. Em **Source**, selecione a branch `main` e a pasta `/ (root)`
4. Salve — o link ficará disponível em `https://seuusuario.github.io/nome-do-repo`
